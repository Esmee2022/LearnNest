# Family and educator guide

## Parents and guardians

Create a parent account with an adult email and a strong password. After sign-in, link a child profile using the minimum display name and age/learning level needed. A parent can view only children explicitly linked to their account. Ask the school to invite teacher/staff accounts. Turn on an authenticator app and save the one-time recovery codes in a private place.

## Children

Children use the child learning view with support from a parent or teacher. Choose an activity, follow the short steps, and take breaks when ready. Activities are suggestions, not timed tests; LearnNest has no competitive leaderboard. Child account recovery and sign-in assistance are handled by a parent or school staff member.

## Teachers

Teachers see only assigned children/classes and can record activity attempts and learning notes for those children. Contact the administrator to change a class assignment or account access. Teachers cannot see passwords, security secrets, or unrestricted user lists.

## If you cannot sign in

Check the email address, then use Forgot password. Reset email is available only after the school has configured SMTP delivery. An expired or used invitation link must be reissued by an administrator. Do not share your password or a one-time authentication code with anyone.
